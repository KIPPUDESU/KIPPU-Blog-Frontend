# 卡片间错落复位
## 在设计本次页面的卡片列表时，我希望能够实现一种“错落有致”的视觉效果  
具体来说，就是让每个卡片在页面中一上一下交错地排布，不过于呆板和整齐

---
## 初步想法：
最初我直接在 :class 中书写条件语句  
根据卡片的 id 来判断它是奇数还是偶数，从而控制它的 margin-top 值不同，实现高低错落  
### 代码：
```html
<div :class="jumpHeader ? 'mt-60' : (product.id % 2 === 0 ? 'mt-100' : 'mt-16')"
>
<!-- 上面采用逻辑的嵌套，要么点击后都回到60，要么计算奇偶一个上一个下（错落） -->
```
这个判断逻辑其实也挺直白的：  
- 如果：当前状态是 jumpHeader = true，说明用户点击了触发动画的事件，那么所有卡片统一设置 mt-60，保证它们位置一致，所有错落的卡片重排成一条线
- 否则：根据奇偶性来控制卡片的上下偏移，偶数 mt-100，奇数 mt-16，这样每两个卡片就会一个高一个低，制造交错视觉  
  
这样处理的优势是控制精细，而且状态驱动明确。但也显得有些繁琐  

---
## 第二思路：使用 CSS 自带的 odd: / even: 伪类
### 代码：
```html
<div 
v-for="product in products" 
:key="product.id" 
class="
transition-all duration-800 ease-in-out 
......
odd:mt-16 even:mt-100" 
:class="jumpHeader ? 'mt-60' : 'mt-0'" >
```
省去了手动判断 product.id % 2 的麻烦  
### 也就是这一段
```html
odd:mt-16 even:mt-100
```

---
## 最终决定：
尽管 odd: 和 even: 在很多场景下都非常好用  
但在本项目的具体实现中，**由于还涉及到 jumpHeader 这个状态变量的干预**，以及后续在时间线组件中需要更加细腻地控制卡片的位置  
单纯依赖 CSS 的奇偶样式已经无法满足全部需求  
我还是退回 JavaScript 逻辑来控制 :class，并在其中处理多个状态嵌套的方式。虽然写起来复杂了点，但灵活性更强，也更能应对后期扩展
