## 核心思想

无论使用哪种方法，核心思想都是一样的：

1. 状态管理：在父组件 `index.vue` 中需要有一个“状态”，用来记录当前应该显示哪个组件。例如，一个叫做 `activeView` 的 `ref`。  
2. 子传父：当 `LeftInfoPanel.vue` 中的分类被点击时，它需要通知父组件 `index.vue`，“嘿，用户点击我了，请把 `activeView` 的状态改成 XXX”。这个通知过程就是“子传父通信”。  
3. 动态渲染：父组件 `index.vue` 监听到状态变化后，会根据 `activeView` 的新值，使用 `v-if` 或动态组件 `<component :is="...">` 来渲染对应的组件。

---

## 思路一：使用 `defineEmits`（推荐，最直接）

这是 Vue 中最标准、最直接的子组件向父组件传递数据的方式。

### 步骤分解

1. 在子组件 `LeftInfoPanel.vue` 中：
   - 使用 `defineEmits` 来声明一个自定义事件，比如叫 `change-view`。  
   - 在你的 `v-for` 循环的点击事件处理函数中，调用 `emit` 方法，并把被点击项的唯一标识（比如 `item.name` 或 `idx`）作为参数传出去。

```vue
<!-- app/components/LeftInfoPanel.vue -->
<script setup lang="ts">
const emit = defineEmits(['change-view']);

const categories = [
  { name: '文章列表', componentName: 'ArticlesList' },
  { name: '关于我', componentName: 'AboutMe' },
  { name: '项目作品', componentName: 'Projects' }
];

function onCategoryClick(category) {
  emit('change-view', category.componentName);
}
</script>

<template>
  <div>
    <!-- ... 其他代码 ... -->
    <ul>
      <li v-for="item in categories" :key="item.name" @click="onCategoryClick(item)">
        {{ item.name }}
      </li>
    </ul>
    <!-- ... 其他代码 ... -->
  </div>
</template>
````

2. 在父组件 `index.vue` 中：

   * 在 `<LeftInfoPanel>` 组件的标签上，使用 `@change-view` 来监听子组件触发的事件。
   * 创建一个 `ref`（例如 `activeComponentName`）来保存当前应该显示的组件名。
   * 使用动态组件 `<component :is="...">`，它的 `:is` 属性绑定到你的 `activeComponentName` 状态。
   * 为了让 Vue 能找到这些组件，你需要导入它们。

```vue
<!-- app/pages/index.vue -->
<script setup lang="ts">
import { ref, shallowRef } from 'vue';
import ArticlesList from '~/components/ArticlesList.vue';
// import AboutMe from '~/components/AboutMe.vue';
// import Projects from '~/components/Projects.vue';

const componentMap = {
  ArticlesList,
  // AboutMe,
  // Projects,
};

const activeComponentName = ref('ArticlesList');

function handleViewChange(componentName: string) {
  activeComponentName.value = componentName;
}
</script>

<template>
  <div>
    <LeftInfoPanel @change-view="handleViewChange" />
    <keep-alive>
      <component :is="componentMap[activeComponentName]" />
    </keep-alive>
  </div>
</template>
```

## 思路二：使用状态管理库 Pinia

如果你的应用中有很多组件需要知道“当前应该显示哪个视图”这个状态，或者你希望这个状态能被全局共享，那么使用 Pinia 会更强大、更规范。

1. 创建一个 Store (`app/stores/viewStore.ts`):  
  
```ts
import { defineStore } from 'pinia';

export const useViewStore = defineStore('view', {
  state: () => ({
    activeView: 'ArticlesList' as string,
  }),
  actions: {
    setView(viewName: string) {
      this.activeView = viewName;
    },
  },
});
```

2. 在子组件 `LeftInfoPanel.vue` 中：

```vue
<script setup lang="ts">
import { useViewStore } from '~/stores/viewStore';

const viewStore = useViewStore();

const categories = [
  { name: '文章列表', componentName: 'ArticlesList' },
  { name: '关于我', componentName: 'AboutMe' },
  { name: '项目作品', componentName: 'Projects' }
];

function onCategoryClick(category) {
  viewStore.setView(category.componentName);
}
</script>

<template>
  <!-- 与思路一相同的模板 -->
</template>
```

3. 在父组件 `index.vue` 中：

```vue
<script setup lang="ts">
import { computed, shallowRef } from 'vue';
import { useViewStore } from '~/stores/viewStore';
import ArticlesList from '~/components/ArticlesList.vue';
// import AboutMe from '~/components/AboutMe.vue';
// import Projects from '~/components/Projects.vue';

const viewStore = useViewStore();

const componentMap = {
  ArticlesList,
  // AboutMe,
  // Projects,
};

const activeComponent = computed(() => componentMap[viewStore.activeView]);
</script>

<template>
  <div>
    <LeftInfoPanel />
    <keep-alive>
      <component :is="activeComponent" />
    </keep-alive>
  </div>
</template>
```

---

### 如何选择？
  
**思路一 (`defineEmits`)**：最适合当前父子直接关系的场景，代码简单、直接，符合 Vue 的设计哲学。  
**思路二 (Pinia)**：适用于需要跨组件共享视图状态的场景，便于未来扩展。  
  
建议先从思路一开始，若后续需求增多，再迁移到 Pinia 方案也十分便捷。
