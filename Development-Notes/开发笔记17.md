feat(content): add description field to content front-matter and configure site metadata

### 功能描述

本次提交为博客内容（文章、分享、歌曲、视频）的 front-matter 增加了 `description` 字段，并配置了 Nuxt 站点的全局元数据，旨在提升内容的 SEO 表现和可发现性。

### 主要特性

- **内容描述字段**:
    - 在 `content.config.ts` 中为 `blog`、`shares`、`songs` 和 `videos` 集合的 schema 添加了可选的 `description` 字段。
    - 为所有现有博文（`content/blog/*.md`）填充了 `description` 字段，内容为文章的首句或简要概述。
    - 为 `content/shares/*.md`、`content/songs/*.md` 和 `content/videos/*.md` 文件添加了空的 `description` 字段。

- **站点元数据配置**:
    - 在 `nuxt.config.ts` 中新增了 `site` 配置对象，包含了 `url`、`name`、`description` 和 `defaultLocale` 等全局站点信息。

- **格式优化**:
    - 修正了部分 Markdown 文件中的格式问题，例如反引号转义和文件末尾的空行。
    - 修复了 `content/songs/07.限りなく灰色へ.md` 中的一个日文歌名错别字。
